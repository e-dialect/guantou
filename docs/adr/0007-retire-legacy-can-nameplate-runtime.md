# ADR-0007：退役 Can / Nameplate 旧运行时

- 状态：已接受
- 日期：2026-09-05

## 背景

旧模型把一次录音作为 Can，再以 Nameplate、Flavor、Package 和 Pronunciation 组合出
解释，并按支持数或权重选择主展示。这会把同一旧词条在不同地区的录音迁成多个内容
主体，也无法自然表达无录音词条、同形异义异读词以及一段录音关联多个词条。

## 决策

公开产品和 API 全面使用 Entry / Recording V2。词条与录音多对多关联；原始证据不可
覆写；不同解释可以并存，由有期限的整理授权和可追溯操作完成修订，不自动按权重选主。

旧表及历史 migration 暂时保留为只读归档，以便审计和回溯。活动 importer 只写 V2，
公开 router、OpenAPI、前端页面、服务和测试不再引用旧领域。删除历史表需要单独的数据
保留评审，不属于本次运行时切换。

## 后果

- 无录音词条可直接搜索并显示待补音。
- 同形异读异义以多个 Entry 返回，不再由一个写法对象承载模糊义项。
- 既有旧库可重复导入 V2，而不会继续产生旧对象。
- 旧链接返回 404；客户端必须使用 `/entries/`、`/recordings/` 等 V2 路径。
- 数据库暂时同时存在活动 V2 表和只读历史表，但只有 V2 是产品事实来源。
