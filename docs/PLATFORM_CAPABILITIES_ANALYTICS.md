# 客户端能力矩阵与产品分析

## 能力开关

客户端最终可用能力是“该构建已编译的能力”与“服务端远程开关”的交集。远程配置只能关闭功能，不能让 H5 凭空获得微信开放能力，也不能绕过客户端代码和权限声明。

`GET /site-settings/capabilities` 返回所有已知开关。后台的 `SiteSettings.remote_capabilities` 只接受已登记的布尔键；缺失键按开启处理，以便旧配置平滑升级。客户端优先读取服务端值，网络失败时最多使用 24 小时内的缓存，之后回到构建默认值。不可用操作必须显示以下两类原因之一：

- 当前构建未包含：建议更新或改用支持的客户端；
- 服务端暂时关闭：说明功能正在维护，其他不受影响的路径仍可使用。

| 能力 | H5 | 微信小程序 | 远程可关闭 |
| --- | --- | --- | --- |
| 听音流 | 是 | 是 | 是 |
| 词条搜索 | 是 | 是 | 是 |
| 录音与提交 | 是 | 是 | 是 |
| 地区使用补证 | 是 | 是 | 是 |
| 整理工作台 | 是 | 是 | 是 |
| 微信开放授权 | 否 | 是 | 是 |

微信配置不申请 `scope.userLocation`，后台模式仅保留音频。地区信息只来自用户在统一方言树中的主动选择，不能由设备位置推断。

## 第一方产品事件

事件只回答核心任务是否被使用、是否成功，不还原个人内容。

| 事件 | 触发点 | 允许的低基数字段 |
| --- | --- | --- |
| `listen_feed_view` | 进入或切换听音流 | `tab` |
| `entry_search` | 词条搜索完成 | 结果分桶、启用筛选数 |
| `recording_submit` | 录音提交结束 | 是否关联已有词条 |
| `evidence_submit` | “我这里也这么说”结束 | 无内容字段 |
| `curation_task_complete` | 整理结论提交结束 | 待办类型 |
| `capability_degraded` | 用户触发不可用能力 | 能力名、降级原因 |

客户端和服务端双重白名单禁止搜索原文、词条/录音 ID、账号 ID、昵称、联系方式、录音内容、方言限定码、经纬度和设备位置。客户端请求不携带登录令牌或全站 visitor id，产品事件路径也不进入通用访问审计。客户端会话 ID 不落库；服务端使用密钥和日期生成每日不同的散列，因此不能跨日拼接个人路径。

## 保留与汇总

`ProductEvent` 是短期原始明细，最长保留 90 天。`ProductEventDailySummary` 只保存日期、事件、终端、页面、结果、次数与当日会话数，可长期保留。每个自然日首次收到事件时会尝试执行一次汇总与清理；部署任务还应每日运行：

```bash
python manage.py aggregate_product_events
```

`PRODUCT_EVENT_RETENTION_DAYS` 可配置为 1–90，生产环境不得设置更大的值。汇总和清理可重复执行，不会累加重复计数。

## 分析口径

- 听：按终端和听音流 Tab 看访问量，不计算跨日用户数。
- 查：成功、空结果、失败分别统计；只保留结果数分桶，不保留查询词。
- 录：提交成功率与是否主动关联已有词条，不读取录音本身。
- 补证：只统计动作结果，地区在业务表中保存，不复制到分析事件。
- 整理：按待办类型统计完成结果，不复制审核理由、证据或目标 ID。

任何需要用户级漏斗、搜索原词分析或位置推断的需求必须重新做隐私评审，不能扩展当前 `metadata` 白名单解决。
