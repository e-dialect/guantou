# 总览：用户一天怎么用

```
打开 App
 → 登录 / 选方言
 → 首页刷同方言
 → 点进罐头/博文互动
 → 去词条查不会的
 → 录一罐 / 用同款发帖
 → 进方言圈
 → 看发现榜与话题
 → 收消息
 → 管「我的」罐头库与资料
```

# 一、启动与登录

## 1.1 打开 App（未登录）

**可见：**  
- 可先进入「查词」或公开内容预览（体现词典价值）  
- 底部若显示完整 Tab，点「发布 / 关注 / 赞」会拦登录  

**策略：**  
- 游客：**查词、听词典发音、看部分公开流**（可选）  
- 需登录：**录罐、发帖、关注、评论、赞、用同款、进圈操作、私信**

## 1.2 登录 / 注册

**入口：** 我的、发布拦截、关注拦截等。  

**流程：**  
1. 手机号 + 验证码（或微信，MVP 一种即可）  
2. 新用户 → 资料与方言引导  
3. 老用户 → 若已有主方言，进首页；若无，补选方言  

**注意：** 登录成功回到「拦截前页面」（想发布就回发布，想关注就回个人页）。

## 1.3 首次方言身份（关键，等同注册第二步）

**页面目的：** 没有主方言，后面「同方言流」无法成立。  

**步骤：**  
1. **选主方言**（必选，列表尽量复用你们词库的方言分类）  
2. **还会哪些方言**（多选，可跳过）  
3. **家乡 / 常住地**（可选，供同城）  
4. 完成 → 进入首页，并可用「推荐同方言创作者」导流（见下）  

**展示：** 选项带例词试听更佳（接词典发音），降低选错方言。  

**完成态：** 个人资料写入 `primaryDialect`，头像旁可显示方言角标。

## 1.4 登录后冷启动推荐（可选但强烈建议）

**页面：** 「关注几位同方言的人，首页会更有意思」  
- 展示同方言作者、官方「每日一词」号、方言圈主  
- 一键关注多个 → 进入首页关注流不至于全空

# 二、首页信息流（方言微博的主场）

## 2.1 顶栏 Tab

建议：`同方言`（默认）| `关注` | `推荐` | `同城`（可二期）

### A. 同方言流（默认首页）

**是什么：** 主方言下的公开博文（罐头为主）。  
**为何默认：** 新用户关注少，同方言也能立刻有内容，产品「姓方言」。  

**卡片上有：**  
- 作者头像、昵称、**方言角标**、时间  
- 短文案  
- **罐头播放区**：播放键、时长、一行字幕、方言标签  
- 若关联词条：小标签「词：xxx」可点进词典  
- 若用同款：显示「使用了 @某人 的罐头」  
- 底栏：赞、评、转、**用同款**、更多（举报/不感兴趣）

**操作：**  
- 点播放 → 全局只播这一条，滑走暂停  
- 点头像 → 他人主页  
- 点词条标签 → 词条详情（释义+发音）  
- 点赞/评论/转发/用同款 → 见后文  

**空态：** 「这个方言暂时还少，去录第一罐 / 去发现热罐 / 切换看看别的方言」  

### B. 关注流

**是什么：** 只看关注的人。  
**空态：** 引导去「推荐关注」或发现同方言作者，而不是空白。  

### C. 推荐流

**是什么：** 跨一点视野，但仍 **方言加权**（同方言、完播高、用同款多）。  
不是纯娱乐热搜照搬。  

### D. 同城流（P1）

按地区；文案强调「乡音」，不是本地资讯客户端。

## 2.2 下拉刷新 / 加载更多

四态：骨架加载、成功列表、失败重试、到底提示。  
返回详情后再回列表，尽量记住滚动位置。

# 三、博文详情

**进入：** 点卡片非按钮区域，或评论入口。  

**页内：**  
- 完整文案、图片（若有）、完整罐头播放与字幕  
- 关联词条卡：短释义 +「听词典发音」+「进词条」  
- 转发链 / 用同款来源  
- 评论列表  
- 底栏：赞、评、转、用同款、分享  

**评论：**  
1. 点评论 → 输入框  
2. 发文字评（P0）  
3. 语音评（P1）：录短语音当迷你回罐  
4. 回复某条评论（P1 盖楼）  

**未登录：** 可看，互动跳登录。

# 四、发布体系（中心按钮）

点底部 **「录一罐 / 发布」** → 先选模式（或合在一个发布器里）。

## 4.1 模式一：录方言罐头（主路径）

**步骤详解：**

1. **选方言**（默认主方言，可改；决定标签与分发）  
2. **按住录音**（如 3～15 秒；过短过长有提示）  
3. **试听** → 满意或重录  
4. **写字幕**（手输；有 ASR 则自动填但必可改——方言识别常不准）  
5. **场景标签**（吐槽、打招呼、口头禅等，可选）  
6. **关联词条**（可选）：搜词绑定，方便别人回查意思  
7. **可见性**：公开 / 仅自己（私密练习）  
8. 三选一提交：  
   - 存草稿  
   - **只存进罐头库**  
   - **存库并去发博**（带上该罐头进发布器）  

**权限异常：** 无麦克风 → 说明引导去系统设置。  
**上传中：** 进度条；失败保留草稿。  

## 4.2 模式二：写博文（微博感）

**页内工具：**  
- 文案输入（可短）  
- **插入罐头**：从「我的库 / 热门 / 用同款带入」选  
- 插入图片（P1）  
- 加话题 `#`  
- @好友（P1）  
- 选方言圈（可选）  
- 再关联词条（可选）  
- 可见性：公开 / 粉丝 / 自己（P1）  

**校验：** 无文字且无罐头不能发；有罐无文字可以发。  

**成功：** Toast → 跳新帖详情或回首页并把新帖插顶。  

## 4.3 「用同款」怎么进发布

**入口：** Feed 卡片、罐头详情、博文详情。  

**流程：**  
1. 点「用同款」  
2. 进入写博文页，**已插入该罐头（引用 canId）**  
3. 用户加自己的文字、话题、圈子  
4. 发布 → 原罐头 `useCount+1` → 原作者收「用同款」通知  
5. 新帖展示「使用了 @原作者 的罐头」  

与转发区别：  
- **转发**：传播「那条帖」  
- **用同款**：拿「语音素材」自己再发一条

# 五、罐头库与罐头详情

## 5.1 我的罐头库

**入口：** 我的 → 罐头库；发布器「从库选择」。  

**Tab：** 原创 | 收藏 | 草稿  

**列表项：** 封面/表情、字幕摘要、方言、时长、使用次数、状态（草稿/审核中/已发布）  

**操作：** 播放、用它发博、编辑（限草稿）、删除、分享（P1）  

**空态：** 「录第一个方言罐头」主按钮。  

## 5.2 罐头详情

**内容：**  
- 大播放器 + 全文字幕  
- 作者、方言、场景、播放数、用同款数  
- **词条卡**（若有关联）：意思摘要、词典发音、进词条、**再录一罐**  
- 按钮：用同款、收藏、举报  
- 「引用了它的博文」  
- 「同词条其他罐头」

# 六、词典（已有能力 + 要加的衔接）

## 6.1 搜词 / 查词（已有增强）

**入口：** 发现顶搜、首页搜、词条收藏、全局搜里的「词条 Tab」。  

**已有：** 出词条列表 → 进词条看 **意思 + 发音**。  

## 6.2 词条详情（改造重点）

**上半（已有）：** 词形、释义、发音播放、例句等。  

**下半（必加）：**  

1. 主按钮 **「用这个词录一罐」**  
   - 进录制页，预带 `wordId`、方言、字幕可预填该词  
2. 模块 **「大家怎么说」**  
   - 相关热罐列表；空则「成为第一个录的人」  
3. （P1）相关博文、收藏词条、纠错反馈  

**闭环：** 查会 → 录出 → 发到流 → 别人点词条再查会。  

## 6.3 词典发音 vs 罐头播放

两套音频要 **互斥**：播罐头停词典音，反之亦然，统一走全局播放器。

# 七、关注与个人主页

## 7.1 关注 / 取关

**入口：** 他人主页、Feed 头像旁、推荐关注列表。  
**未登录：** 拦登录。  
**结果：** 进入你的关注流；对方粉丝数 +1；可推「新粉丝」通知。  

## 7.2 他人主页

**头区：** 头像、昵称、主方言角标、简介、地区、关注/粉丝/获赞、**罐头被用同款数**  
**按钮：** 关注、私信（P1）、更多（拉黑举报）  

**Tab：**  
- 博文  
- 罐头（原创）  
- （P1）收藏公开部分  

## 7.3 我的主页

同结构 + 「编辑资料」。  
**编辑资料：** 头像昵称简介、主方言、会的方言、地区。  
主方言修改建议谨慎（可限制频率），因影响分发。  

## 7.4 关注 / 粉丝列表

列表展示方言角标；可点进主页；支持移除粉丝/备注等（P1/P2）。

# 八、互动：赞、评、转

## 8.1 点赞
卡片或详情一点即赞；乐观更新；再点取消；通知作者。

## 8.2 评论
见博文详情；通知作者；回复评论通知被回复人（P1）。

## 8.3 转发
- 直接转发  
- 转发并加评论  
新动态出现在关注者流里，带来源帖与原罐头播放。

# 九、方言圈（超话方言版）

## 9.1 圈子广场

**入口：** 底部「方言圈」Tab。  
**筛选：** 按语系/方言/热度/我加入的。  
**卡片：** 封面、圈名、主方言、成员数、一句话简介。  

## 9.2 圈子详情

- 封面、简介、主方言、成员数  
- **加入 / 已加入**  
- 公告（P1）  
- Tab：最新 / 热门；**罐头墙**（P0/P1）  
- （P1）圈内词表——精选词条，点进词典  
- 发帖按钮 → 发布器默认带本圈 + 本地方言  

## 9.3 圈内发帖 / 刷帖
与首页类似，但内容限定本圈；强调归属与方言纯净度（规则里可写「请用本地方言录音」）。

## 9.4 签到 / 挑战（P1）
每日签到；话题挑战如「用本地方言说同一句话」→ 聚合到话题页。

# 十、发现与话题

## 10.1 发现页结构

1. 搜索入口  
2. 方言切换（看别的方言热门）  
3. **热罐头榜**（播放、完播、用同款）  
4. **热词条**（接词典）  
5. **方言热搜 / 话题**  
6. 推荐方言圈、推荐创作者  
7. **今日方言词**：词条 + 示范罐  

## 10.2 综合搜索

Tab：`综合 | 词条 | 罐头 | 用户 | 圈子 | 话题 | 博文`  
历史记录：最近搜词 + 最近搜人。  

## 10.3 话题页

- 话题名、简介、参与人数  
- 置顶热罐墙  
- 博文流  
- 「参与话题」→ 发布器预填 `#话题`  
可再挂关联词条（方言挑战用词）。

# 十二、「我的」汇总入口

建议入口排布：  

- 头区进自己的主页  
- 罐头库  
- 草稿箱  
- 我的收藏（博文 / 罐头 / **词条**）  
- 我加入的方言圈  
- 消息（若未单独 Tab）  
- 推荐关注  
- 设置：账号安全、隐私（谁可评论/私信、是否公开展示方言）、通知开关、清除缓存、协议、退出/注销

# 十三、安全相关（穿插在各功能里）

- 任意博文/罐头/评论/用户：**举报**  
- 个人页更多：**拉黑**  
- 发布后可能：**审核中**仅自己可见 → 通过后公开 → 拒绝并通知原因  
- 录制：时长、体积、格式限制提示

# 十四、一条「完整演示脚本」（从登录到各功能串起来）

适合周五组会按顺序点：

1. **注册登录** → 选主方言「四川话」  
2. **推荐关注** 2～3 人（可跳过）  
3. **首页同方言流** 刷到一条罐头 → 播放听字幕  
4. 点卡片上 **词条标签** → 看释义、听词典发音  
5. 回帖子 → **点赞 + 发评论**  
6. 点 **用同款** → 加一句自己的话 → 发布成功  
7. 底部 **录一罐**：录 5 秒 → 写字幕 → 关联刚才词条 → 存库并发博  
8. 打开 **词条详情** → 看到「大家怎么说」里出现自己的罐  
9. 进 **方言圈** → 加入 → 圈内再发一条  
10. 打开 **发现** → 看热罐榜 / 今日一词  
11. 打开 **消息** → 看到赞或用同款通知  
12. **我的 → 罐头库** 看到原创与使用次数  

这条脚本走完，就把「方言语音微博」主闭环讲圆了。
