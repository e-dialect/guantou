## 前端交互设计 v1（产品体验组）

以下为方言罐头核心页面的交互设计规格，供前端组对照开发。2026\.07\.23 出品。

### 一、核心页面说明（6 屏）

#### 1\. 首页 \(pages/index\)

顶部品牌区（"方言罐头" \+ slogan）→ 搜索框 → 四宫格快捷入口（货架/装罐/图鉴/我的）→ "最近的罐头"列表。

**底部 Tab 导航：**首页 / 货架 / 装罐（主色突出）/ 图鉴 / 我的。

**交互要点：**"装罐"Tab 用主色 \#FF6B35 突出，引导核心行为。搜索框点击跳转搜索页。罐头卡片展示：写法 \+ 方言点 \+ 铭牌数 \+ 状态标签。

#### 2\. 装罐页 \(pages/cans/create\)

**必填（3项）：**普通话概念 \+ 方言点（级联选择器）\+ 录音（按住录音/上传）。

**选填：**候选写法、释义、包装类型（正字/借字/俗写/拟音）、来源说明。

**交互要点：**门槛极低——不会写正字也能录一罐。录音区用虚线框 \+ 麦克风图标，支持按住录音和文件上传两种方式。底部提示"不会写正字也没关系，先录下来最重要"。

**异常态：**录音权限被拒→弹提示；网络断开→本地暂存草稿。

**成功态：**提交后跳转罐头详情页，提示"你的罐头已入库，状态为 unlabeled，等待社区贴铭牌"。

#### 3\. 罐头详情 \(pages/cans/details\)

**Hero 区：**主铭牌写法（大字）\+ 普通话概念 \+ 方言点 \+ 播放按钮 \+ 状态标签。

**铭牌列表：**主铭牌高亮卡片（橙色边框）置顶，副铭牌普通卡片排列。每张铭牌展示：写法、释义、证据来源、发布者、权重值、"▲ 支持"按钮。

**底部：**"\+ 我也来贴一张铭牌"按钮。

**交互要点：**投票不是"点赞"——按钮文案为"支持"，展示权重数字。异议通过"贴新铭牌"表达，系统没有"反对/踩"按钮。主铭牌切换时高亮卡片自动更换。争议态（前两名权重差≤2）时顶部显示黄色提示条"存在争议"。

#### 4\. 货架 \(pages/shelves/index\)

按主题分类浏览罐头。每个货架卡片：emoji 图标 \+ 主题名 \+ 罐头数 \+ 代表词预览。点进去是该主题下的罐头列表。

**空态：**"正在筹备中，敬请期待" \+ 引导去装罐。

#### 5\. 图鉴 \(pages/flavors/index\)

按义项（风味）浏览。顶部搜索框，下方风味卡片列表：义项名 \+ 方言点数 \+ 关联写法预览 \+ 录音数。点进一个风味可看到各地读音变体和关联罐头。

**与货架的区别：**货架按主题组织（身体部位、亲属称谓），图鉴按语义组织（行走、祖母、膝盖）。

#### 6\. 贴铭牌（弹层/页面）

**必填：**我主张的写法。

**选填：**释义、包装类型（正字/借字/俗写/拟音，单选标签）、证据来源。

**交互要点：**铭牌是"我的主张"不是"正确答案"，措辞避免暗示唯一正确。证据字段鼓励填但不强制。提交后返回罐头详情，新铭牌出现在列表中。

### 二、核心交互流程

#### 流程 A：装罐

首页点"装罐" → 填普通话概念 → 选方言点（级联） → 按住录音/上传 → 必填校验 → 提交成功跳转详情

- 必填：概念 \+ 方言点 \+ 录音（3项）

- 选填：候选写法、释义、包装类型、来源说明

- 录音权限被拒 → 弹提示"需要麦克风权限"

- 网络断开 → 本地暂存草稿，恢复后提示续传

#### 流程 B：铭牌投票

进入罐头详情 → 浏览铭牌列表 → 选择"支持"或"贴新铭牌" → 权重重排 → 主铭牌更新

- 支持：点击"▲ 支持"为铭牌 weight \+1（每人每铭牌限一次）

- 异议：点"\+ 贴铭牌"提出新主张，不是"踩"已有铭牌

- 主铭牌切换：某张副铭牌 weight 超过当前主铭牌时自动切换

- 争议态：最高两张铭牌 weight 差距 ≤ 2 时，罐头标记为 disputed

### 三、状态与边界情况

#### 空态设计

- 首页无罐头：插画 \+ "还没有罐头，来录第一罐吧" \+ 装罐按钮

- 罐头无铭牌：hero 区显示"等待铭牌"，下方大按钮"来贴第一张铭牌"

- 货架/图鉴空："正在筹备中，敬请期待" \+ 推荐去装罐

#### 加载态

- 列表页：骨架屏（3 个灰色卡片占位）

- 详情页：hero 区先展示概念文字，铭牌列表用骨架行

- 录音上传：进度环 \+ "正在上传乡音…"，禁止返回

#### 错误态

- 网络错误：顶部红色 toast "网络不给力，稍后重试"

- 录音失败：弹窗"录音中断，是否重试？"保留已填表单数据

- 401 未登录：跳登录页，登录后自动返回原页面

### 四、罐头状态标签色彩体系

|状态|含义|色值|用途|
|---|---|---|---|
|unlabeled|无铭牌|\#9E9E9E（灰）|新录入的罐头|
|pending|待校验|\#F9A825（黄）|有铭牌但未校验|
|tentative|社区暂定|\#1976D2（蓝）|社区投票形成的共识|
|verified|正品认证|\#388E3C（绿）|管理员/专家认证|
|disputed|争议中|\#D32F2F（红）|前两名铭牌权重接近|
|rejected|已驳回|\#616161（深灰）|审核不通过|
