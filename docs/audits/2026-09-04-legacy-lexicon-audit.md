# 兴化语记旧库词条审计基线

## 目的

本报告为“词条—录音”重构提供可重复核对的源数据基线。审计对象是仓库根目录的 `兴化语记当前数据.sqlite3`，工具只读取 `word_word` 和 `word_pronunciation`，不写源库、目标库或候选结果。

运行方式：

```bash
python3 tools/materials/puxian/audit_legacy_entries.py \
  兴化语记当前数据.sqlite3 --format markdown
```

需要完整候选数据时使用默认 JSON 输出；Markdown 只展示每类候选的前若干条示例。

## 候选而非结论

审计器只产生四类人工任务：

| 候选 | 数量 | 人工需要判断什么 |
| --- | ---: | --- |
| 分义建议 | 307 | ①②表示独立分义、相关子义、语法用法，还是例句分组 |
| 编号异常 | 4 | 编号缺失、重复，或圈号其实来自年份和数量 |
| 多地区或多读音 | 55 | 地区音变、文白异读、代际差异，还是不同词条 |
| 同地多读音拆词条复核 | 2 | 同一地区内是否存在不同词、不同读音身份或录入差异 |
| 可能重复 | 99组 | 相同写法是否同词；不得仅凭字面自动合并 |

两条同地多读音候选是：

- 旧词条 `#4243 曝日`，城厢区龙桥街道存在两套 IPA 记录。
- 旧词条 `#6048 笏石`，秀屿区笏石镇存在两套 IPA 记录。

四条圈号异常记录是：

- `#4505 三头乓`：圈号混入数量，疑似字符识别或录入问题。
- `#636 不之何`：出现①、③，缺少②。
- `#4108 乌鸡母`：圈号混入民国年份数字。
- `#1828 缀`：连续两个释义都标为①。

重复写法中已经能看到“同形不等于同词”。例如：

- `上` 的旧记录 `#1023` 表示“生长”，`#1097` 表示“汲取”。
- `下` 的旧记录 `#2592` 表示“许愿”，`#3253` 表示“低或低于平均”。
- `[冖赣]` 的旧记录 `#2013`、`#3147` 标准读音和用法均不同。

## 对迁移设计的约束

1. 每个 `word_word.id` 必须先得到可追溯的初始 Entry，不能等有录音才创建词条。
2. 每个 `word_pronunciation.id` 只创建一条 Recording，并通过关系记录连接到来源 Entry；同一旧词的多条录音不得复制 Entry。
3. 4,969 个无录音词条照常迁移并可显示“待补音”。
4. 99 组相同写法保持独立，输出可能重复候选，由整理员结合释义、读音、地区和来源确认。
5. 307 条编号定义保留原文；解析结果进入分义建议，不能直接成为不可逆的自动拆分。
6. 同地多读音只提高人工复核优先级，不能由脚本断言为不同词条。
7. 旧标准 IPA、拼音没有地区字段，按已确认规则映射到 `闽.莆仙.莆田.城里`；录音自己的县镇信息仍独立映射为使用地区。
8. 旧词条和录音的可见性分别保留；4 条隐藏词条和126条隐藏录音不得因迁移自动公开。

## 可重复性

对应测试位于 `tools/materials/tests/test_audit_legacy_entries.py`，覆盖统计、候选分类、缺失表结构和源文件哈希不变。材料工具测试命令：

```bash
python3 -m unittest discover tools/materials/tests
```

首次基线运行结果：29 项测试通过，其中1项按环境条件跳过。
