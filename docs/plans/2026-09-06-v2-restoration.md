# v2 功能回归与体验更新

## 约束

信息架构优先，其次 UI/UX，最后旧代码复用。保持“听／查／录／我”和 Entry／Recording 模型；不迁移旧业务数据，不恢复旧公共接口、独立动态、用同款或投票选主。

## 实现分组

1. 草稿与录音详情：新存储版本、账号隔离、持久音频、保存失败保留文字、显式恢复、录音独立分享。
2. 集盒与搜索：词条作为一级目录，录音在词条下按地区分组；无关联录音在待整理区，用户明确确认归档。搜索联想与本地历史，公开内容互动发现。
3. 发现与轻互动：关注作者录音流、稳定每日精选、随机试听；录音点赞、评论、一层回复、评论点赞与消息提醒。
4. 视觉与验证：沿用主题 token，盒签、纸白、松绿及少量金色；同步主题预览，覆盖 H5 明暗主题、桌面、小程序构建。

## 验收

集盒一音多词去重、词条身份不合并、不自动修改关联；权限与隐藏内容过滤；草稿账号隔离、刷新恢复、音频保存失败；评论幂等重试及通知去重；联想竞态、每日稳定、关注范围。运行后端完整测试、前端单测、lint、两端构建、API 契约及浏览器路径验证。
